# Unity Wizard
Unity Wizard is (will be) a project made to quickly configure and set up a Unity project. 

## Intended Usage
1. At the start of a new Unity project, open Unity Wizard to set up your project
2. While working on a Unity project, open Unity Wizard to add missing pieces

## Intended Features
* Version control configuration
    - CI / automatic builds (github)
    - README setup
    - Version control file settings
    - PR template (github)
    - gitignore
* Package setup
    - DOTween
    - [Pear Shader](https://gumoraes11.github.io/Pear-Shader/)
    - TextMeshPro imports
* Code system inclusion/generation
    - i.e. creating input handling systems
* Folder setup
    - Configurable presets
    - ASMDEFs
* Input setup
    - Built-in abstraction layer
    - Controller you can select buttons to use on
* Project settings
    - i.e. Gravity at 20 instead of 9.81
    - Render pipeline configurator
* General Utilities
    - Camera to viewport view
